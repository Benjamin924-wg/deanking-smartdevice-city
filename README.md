# DeanKing Smartdevice City

## Run locally

1. Install Node.js LTS.
2. Open PowerShell in this folder.
3. Run `npm install`.
4. Run `npm start`.
5. Open `http://localhost:3000/`.

Use `http://localhost:3000/cart.html` for the cart. Opening the HTML files directly with `file://` will not provide the product manager API.

## Deployment

The storefront and product manager backend must be hosted where Node.js runs. Render can run this project as a Node web service.
